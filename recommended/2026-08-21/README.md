### 1. AbdomenNet — 비조영 CT 급성 복부질환 재단 모델 (Nature Communications)
3개의 독립 외부 코호트(환자 2528명)에서 검증하고, 다기관·교차 판독 연구로 방사선의 판독 정확도(AUROC 0.812→0.924) 향상을 입증했습니다. 본 코호트도 5개 기관에서 수집되어 기관 간 이질성이 중요한 이슈이므로, 다기관 외부 검증 설계 측면에서 참고할 만합니다. 다만 대상 모달리티(비조영 CT)와 질환(급성 복부질환)이 본 코호트(흉부 X-ray)와 다르므로 직접적인 임상 적용 근거로 삼을 수는 없습니다.

### 2. 다기관 폐결절 악성도 추정 딥러닝 모델 (European Radiology)
3개 기관, 269개 결절(환자 231명)에서 두 딥러닝 모델이 임상 표준(Brock 모델)보다 우수하고 기관 간 일관된 성능(AUC 0.72–0.76)을 보였습니다. 본 코호트에도 Nodule 소견이 7건 존재하며 5개 기관에서 수집되어, 결절 판독의 기관 간 일관성이라는 주제가 직접 맞물립니다. 다만 CT 기반 연구로, X-ray 상 결절 검출에 그대로 적용되는지는 별도 확인이 필요합니다.

### 3. UniMedDiff — 지식 강화 확산 모델 기반 의료영상 생성 (npj Digital Medicine)
판독문 기반으로 11개 폐 병리를 반영한 흉부 X-ray를 생성하며, 실제 데이터 1%만 추가해도 전체 데이터 학습에 근접한 분류 성능을 달성했습니다. 본 코호트는 272건·153명으로 규모가 작고 Nodule, Fibrosis 같은 희귀 소견의 표본이 매우 적어, 데이터 증강을 통한 성능 보완이라는 문제의식이 실질적으로 맞물립니다. 다만 이 논문은 생성 품질과 다운스트림 분류 성능만 보고하며 실제 임상 검증 결과는 포함하지 않습니다.
